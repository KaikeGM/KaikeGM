<a name="b2b-credit-risk-prediction"></a>
## 💳 B2B Credit Risk Prediction

Pipeline de **Machine Learning para previsão de risco de inadimplência B2B**, utilizando dados históricos e comportamentais para apoiar segmentação de risco e priorização de clientes.

### Principais técnicas

- Análise exploratória de dados
- Feature Engineering temporal
- Validação **Out-of-Time**
- Prevenção de **Data Leakage**
- Regressão Logística como baseline
- HistGradientBoosting
- XGBoost
- CatBoost
- Calibração de probabilidades
- Interpretação estatística com Odds Ratio

### Resultados

| Métrica | Resultado |
|---|---:|
| ROC-AUC | **0.959** |
| KS | **0.815** |

**Stack:** `Python` • `Pandas` • `Scikit-Learn` • `XGBoost` • `CatBoost`

[**Ver projeto →**](https://github.com/KaikeGM/data-science-case-credit-risk-B2B)

<a name="sentiment-analysis-api"></a>
## 💬 Sentiment Analysis API

Projeto colaborativo de **Processamento de Linguagem Natural (NLP)** para classificação de sentimentos em textos em português e espanhol.

A solução combina processamento de texto, vetorização e Machine Learning com uma API para disponibilização das previsões.

### Principais técnicas

- Processamento de dados não estruturados
- TF-IDF
- Vetorização de textos
- Classificação de sentimentos
- Processamento em chunks
- API de inferência com FastAPI

**Stack:** `Python` • `Scikit-Learn` • `NumPy` • `TF-IDF` • `FastAPI`

[**Ver projeto →**](https://github.com/Hackaton-ONE/hackathon-DataScience)
