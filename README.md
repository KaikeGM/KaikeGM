# 🚀 Projetos em Destaque

## 💳 Previsão de Risco de Crédito B2B

Modelo de **Machine Learning para previsão de risco de inadimplência**, utilizando dados históricos e comportamentais para apoiar segmentação de risco e priorização de clientes.

### Principais técnicas

- Análise exploratória de dados
- Engenharia de atributos
- Validação temporal **out-of-time**
- Prevenção de **data leakage**
- Regressão Logística
- HistGradientBoosting
- XGBoost
- CatBoost
- Calibração de probabilidades
- Interpretação estatística com Odds Ratio

### Resultados

- **AUC-ROC: 0,959**
- **KS: 0,815**

**Stack:** Python • Pandas • Scikit-Learn • XGBoost • CatBoost • Estatística

🔗 [Ver projeto](https://github.com/KaikeGM/data-science-case-credit-risk-B2B)
